# Disaster Risk Prediction

**Goal:** Analyze global disaster data to identify patterns and predict high-risk regions for future events.

**Tech Stack:**  
- Python (pandas, numpy, scikit-learn, matplotlib, seaborn)  
- Jupyter Notebook

**Key Work:**  
- Data preprocessing and cleaning  
- Exploratory Data Analysis (EDA)  
- Feature engineering (historical disaster frequency, region data)  
- Classification models for high-risk region prediction  
- Model evaluation using Accuracy, Precision, Recall, F1-score

**Dataset:**  
- Global disaster datasets from Kaggle or open sources


**Outcome:**  
- Identified high-risk regions for future disaster events  
- Built an end-to-end ML pipeline for disaster risk prediction
